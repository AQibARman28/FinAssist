# Sprint plans and postmortems

These are the working documents from each sprint, kept as a record of how the
features were planned, built and reviewed. They describe the code **as it was at the
time**. Statuses such as "awaiting approval" are historical, and later work has
changed some of what they describe.

For how the app works today, see the root [README](../../README.md),
[`views/PRODUCT.md`](../../views/PRODUCT.md), [`views/DESIGN.md`](../../views/DESIGN.md)
and the [security docs](../security/).

| Sprint | What it covered |
|--------|-----------------|
| SEC-1 | Record attestations (ECDSA), sessions and key management |
| DASH-1 | The first dashboard spending timeline |
| EXP-1 | The expenses page and quick add |
| GOAL-1 | Savings goals, the cash-flow-aware planner and the suggested split |
| HS-1 | The multi-factor financial health score |
| INC-1 | Income (one-off and recurring) and user-owned categories |
